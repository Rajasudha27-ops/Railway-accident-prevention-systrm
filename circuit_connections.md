| Component | Arduino Pin |
|-----------|-------------|
| Ultrasonic TRIG | D3 |
| Ultrasonic ECHO | D4 |
| L298N IN1 | D5 |
| L298N IN2 | D6 |
| L298N ENA | D9 |
| Sensor VCC | 5V |
| Sensor GND | GND |

Motor connects to L298N motor output.
External motor battery connects to the motor driver.
Arduino and motor driver must share GND.
